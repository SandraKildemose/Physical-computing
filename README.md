# Physical-computing

Physical-computing er mit foerste physical computing-program med Arduino. Projektet kombinerer browserkode og Arduino-kode, saa input fra fingre/haand kan bruges til at styre LED eller interaktion.

Dette projekt er lavet selv. Jeg har faaet hjaelp til debug undervejs, men det er ikke et promptet projekt paa samme maade som mine webprojekter. Fokus har vaeret at forstaa koblingen mellem software, hardware og fysisk input.

## Indhold

- Arduino sketch i `finger-led-arduino/`
- JavaScript-filer til finger/haand-input
- HTML-demo til LED-interaktion
- Video af projektet i `Video.mov`

## Status

Projektet er lagt op som en lokal faerdig version med kode og video, saa processen og resultatet kan ses samlet.

Projektet er bygget lokalt og har undervejs vaeret gemt paa en ekstern harddisk. Derfor afspejler GitHub-repository'et ikke hele den lokale udviklingshistorik med mange commits, men fungerer som en samlet upload af den faerdige version.
